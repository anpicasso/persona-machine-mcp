# Changelog

## 0.1.0

- Unofficial stdio bridge for Persona MCP Server V2 using machine-client OAuth.
- EC P-256 / RSA key generation, configuration, public JWKS export, token and health commands.
- In-memory token cache, 90-second refresh skew, and a single retry after a 401.
- Capability-gated tools, resources and prompts; paginated tools and allow/deny filtering.
- Portable Agent Plugins v1 package, offline tests, CI and PyPI trusted-publishing workflow.
